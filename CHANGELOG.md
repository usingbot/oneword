# Changelog

No public release or release date is claimed yet. The initial public version
proposed for this repository is **0.1.0**, matching package.json.

## Unreleased — proposed 0.1.0

- TXT/paste and local text-layer PDF ingestion, editable extracted text with
  immutable originals and revisions; no OCR.
- RSVP-style reading with grouping, timing controls, pause/navigation, static
  context text and fullscreen/focus mode.
- Local IndexedDB library, checkpoints, versioned migrations and atomic
  Personal Backup import/export.
- Editable flashcard decks and content-only Study Pack JSON exchange.
- FSRS scheduling, recall/reveal, four ratings, review history, daily allowance,
  safe undo and stale-tab protection.
- Practice/test quizzes with stable-choice grading, reproducible shuffle,
  reloadable attempts and personal history separate from FSRS.
- Installable PWA shell, offline local study, explicit safe updates and
  migration/recovery hardening.
- Mobile viewport and keyboard/accessibility improvements, synthetic large-data
  measurements and privacy/network verification.
- Release preparation: AGPL-3.0-only metadata, third-party notices, public docs,
  contribution/security policies and core CI checks.

These capabilities summarize accepted M1a–M4a milestones plus M4b release
preparation. Known limitations remain in [README.md](README.md). No tag,
GitHub release or production deployment has been performed as part of M4b.
